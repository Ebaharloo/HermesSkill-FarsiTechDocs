## Terms usually kept in English

Data Lakehouse, CDC, exactly-once, watermark, checkpoint, upsert, Event
Sourcing, Data Pipeline. Use the English term and add a Persian explanation at
first mention.

## Missing term protocol

1. `web_search` for `<English term> فارسی site:faradars.org`, then the same on
   `maktabkhooneh.org` and `nikamooz.com`.
2. `web_search` for the candidate Persian term on `nikamooz.com`.
3. If two sources agree, use that form. If they disagree, use the most common
   form and keep the English term in parentheses at first mention. If none
   uses a Persian form, keep English.
4. Add the chosen form to the document's term table so the rest of the
   document stays consistent.

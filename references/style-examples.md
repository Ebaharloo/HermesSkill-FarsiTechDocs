# Persian Tech Style Examples

| قبل | بعد | چرا |
|---|---|---|
| «در این معماری، دادهها در یک Data Lake ذخیره میشوند.» | «در این معماری، داده‌ها در دریاچه داده ذخیره می‌شوند.» | ترجمه تحت‌اللفظی؛ نبود ZWNJ؛ اصطلاح استاندارد |
| «با توجه به این که حجم دادهها زیاد است، پردازش دستهای انجام میشود.» | «حجم داده‌ها زیاد است؛ بنابراین پردازش دسته‌ای انجام می‌شود.» | حذف الگوی ماشینی «با توجه به این که»؛ ZWNJ |
| «کوئری روی جدول اجرا میشود و سپس پرسوجو نتیجه را برمیگرداند.» | «کوئری روی جدول اجرا می‌شود و نتیجه را برمی‌گرداند.» | یکسان‌سازی اصطلاح؛ حذف تکرار |
| «این سیستم از نظر مقیاسپذیری و دسترسپذیری طراحی شده است.» | «این سیستم برای مقیاس‌پذیری و دسترس‌پذیری طراحی شده است.» | ZWNJ و حرف ربط طبیعی‌تر |

الگوهای ماشینی که باید کوتاه شوند: «با توجه به این که»، «از آنجا که»،
«به منظور»، «در حالی که»، «به صورت» بدون مورد ضروری.
